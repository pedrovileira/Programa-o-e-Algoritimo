# Atividade Remota 01 — Python

**Autor:** Pedro Vileira

Este repositório contém os 10 exercícios da atividade, cada um em seu próprio arquivo Python (`ex01.py` até `ex10.py`).

## Como executar

Com Python 3 instalado, abra o terminal na pasta do projeto e execute, por exemplo:

```bash
python ex01.py
```

Troque `ex01.py` pelo arquivo do exercício desejado.

## Envio para o GitHub

Depois de criar um repositório público vazio no GitHub, abra o terminal nesta pasta e execute:

```bash
git init
git add ex01.py
git commit -m "feat: conclui o exercício 01"
git branch -M main
git remote add origin https://github.com/SEU-USUARIO/NOME-DO-REPOSITORIO.git
git push -u origin main
```

Para registrar os exercícios seguintes individualmente:

```bash
git add ex02.py
git commit -m "feat: conclui o exercício 02"
git push

git add ex03.py
git commit -m "feat: conclui o exercício 03"
git push
```

Repita o mesmo padrão até `ex10.py`. Substitua a URL de exemplo pela URL real do seu repositório.

## Exercícios incluídos

1. Maior entre dois números.
2. Verificação de número positivo, negativo ou zero.
3. Identificação de F ou M.
4. Saudação conforme o turno de estudo.
5. Média de duas notas e situação do aluno.
6. Quadrados dos números de 15 a 200.
7. Tabuada de um número.
8. Soma dos números de 1 a 100.
9. Soma dos números pares de 1 a 500.
10. Números ímpares de 0 a 20.
